# ⚡ REFERENCIA RÁPIDA (30 segundos)

## 🎯 Tu Pregunta Respondida

**¿Cómo agregar un usuario administrador desde el inicio de forma segura para Oracle Cloud?**

**Respuesta:** Usar variables de entorno + AdminDataInitializer (componente Spring Boot).

---

## 🚀 3 PASOS (5 minutos)

### 1️⃣ Generar Contraseña
```bash
openssl rand -base64 32
```
**Guarda el resultado**

### 2️⃣ Variables de Entorno
```bash
export ADMIN_USERNAME="admin"
export ADMIN_PASSWORD="<resultado_paso_1>"
```

### 3️⃣ Ejecutar
```bash
java -jar target/api-0.0.1-SNAPSHOT.jar
```

✅ **Admin creado automáticamente**

## 🔐 Cómo Funciona

1. App arranca → AdminDataInitializer se ejecuta
2. Lee variables: `ADMIN_USERNAME`, `ADMIN_PASSWORD`
3. Verifica si existe admin (no sobrescribe)
4. **Encripta** password con BCrypt
5. Crea usuario ADMIN en BD
6. **Logs**: "✓ Administrador creado"

## 🎯 Para Producción (Oracle Cloud)

```bash
# En OCI Cloud Shell:
export ADMIN_USERNAME="admin_prod"
export ADMIN_PASSWORD=$(openssl rand -base64 32)
java -jar api-0.0.1-SNAPSHOT.jar

# O usar Terraform para automatizar TODO:
cd terraform
terraform apply -var="admin_username=admin_prod" \
                -var="admin_password=$(openssl rand -base64 32)"
```

## 🆘 Problemas?

| Problema | Solución |
|----------|----------|
| "No se encontraron variables" | `export ADMIN_USERNAME=...` |
| "Usuario ya existe" | Normal en 2º arranque. OK. |
| "Contraseña muy corta" | Usar resultado de `openssl rand` |
| "¿Y si olvido la contraseña?" | Resetea en BD o redeploy |
